## 2. Агент (`apps/agent`) — безопасность

Агент выдаёт shell на машине, и до аудита любой, кто дотягивался до порта,
получал его без каких-либо проверок. Исправлено:

- **Инъекции команд.** Все вызовы tmux переведены на `execFile` с массивом
  аргументов (`src/lib/tmux.ts`); цели сессий — точное совпадение (`=имя`),
  ввод в сессию — `send-keys -l --`. Имя сессии проверяется регулярным
  выражением `^[\w-]{1,100}$` в WebSocket-пути, роутах, хуках и при записи
  init-скрипта (`src/lib/validation.ts`).
- **RCE через автообновление.** `?v=` с WebSocket принимает только строгий
  semver; скрипт обновления пишется во временный каталог `mkdtemp` с флагом
  `wx`.
- **`git clone`.** Имя репозитория валидируется, передаётся после `--`,
  путь ограничен `basePath`, `protocol.ext.allow=never`, таймаут 5 мин,
  из текста ошибки вырезаются учётные данные в URL.
- **Любой сайт мог управлять локальным агентом.** Введён allowlist Origin
  (`src/lib/origin.ts`) для HTTP и WebSocket: разрешены `https://247.quivr.com`,
  `http://localhost:3001`, origin из `dashboard.apiUrl`, `agent.allowedOrigins`
  и `AGENT_247_ALLOWED_ORIGINS`. Запросы без Origin (CLI, хук) проходят.
- **Привязка интерфейса.** По умолчанию `127.0.0.1`; `AGENT_247_BIND_HOST`,
  `agent.host` или `CLOUD_AGENT=true` для 0.0.0.0. Туннели подключаются
  локально, поэтому Tailscale/Cloudflare продолжают работать.
- **Падение от кривого заголовка Host** в upgrade-обработчике устранено;
  добавлены обработчики `unhandledRejection` и `server.on('error')`.
- **Логи.** Нажатия клавиш и вывод терминала больше не пишутся в лог.
- **Пейринг.** Токены подписываются случайным секретом процесса (раньше —
  machineId, который сам отдаётся на странице), сравнение подписи
  константное по времени, код — `crypto.randomInt`, HTML экранируется,
  подбор кода ограничен 30 попытками в минуту.
- **Корректность.** Миграции SQLite в транзакции; битый конфиг — явная
  ошибка вместо тихого отката на другой профиль; `kill`/`archive` не
  оставляют расхождений между tmux и БД; утечка памяти в debug-обработчике
  PTY; `new-session -A` против гонки двух клиентов; `AGENT_247_PORT`
  теперь читается агентом и передаётся в сессии для хука.

Тесты: `tests/unit/{validation,origin,tmux}.test.ts`, новые кейсы в
`tests/integration/{api,websocket}.test.ts` (чужой Origin, инъекция в имя
сессии, подмена опций git) и в `terminal/updater/config.test.ts`.
Проверено вживую на одноразовой tmux-сессии: `$(...)`, обратные кавычки и
`;` печатаются буквально, подставленная версия не запускает обновление,
чужой Origin получает 403.

## 3. Веб (`apps/web`)

- **Service worker.** `public/sw.js` переписан вручную: только
  `push`/`notificationclick`/`message`, без precache устаревших чанков и без
  перехвата запросов; регистрируется `ServiceWorkerRegistrar`; `/sw.js`
  отдаётся с `no-store`; хуки push-уведомлений больше не зависают на
  `serviceWorker.ready`.
- **Серверные роуты.** SSRF в `/api/pair/validate` закрыт (строгая проверка
  host, `verified:false` при сбое); `/api/pair/code` — POST только с
  авторизацией, код сгорает после чтения; `/api/push/notify` удаляет подписку
  только при 404/410 и ограничен по частоте; `/api/push/subscribe` проверяет
  владельца; `/api/connections` валидирует ввод, отвечает 400/404/409;
  отладочные `api/test` и `api/testcatch` убраны; тело ответов авторизации
  не логируется; базовые security-заголовки в `next.config.mjs`.
- **Клиент.** Переписан жизненный цикл WebSocket в `SessionPollingContext`
  (утечки сокетов, двойные уведомления, «призрачные» сессии, реконнект
  удалённых агентов); восстановлен автореконнект терминала; Escape закрывает
  только верхний оверлей; терминал не перемонтируется после создания сессии;
  убран запрос разрешения на уведомления при загрузке; имена сессий
  санитизируются под правило агента; доступность — подписи у иконок,
  `role="dialog"`, кнопки Archive/Kill достижимы с клавиатуры.
- Ранее в этой же сессии: битый синтаксис `sw.js`, `<button>` внутри
  `<button>`, URL без схемы в `acknowledge`, `middleware.ts → proxy.ts`,
  `next.config.js → .mjs`.

## 5. CLI (`packages/cli`)

- `247 hooks install` больше не может затереть `~/.claude/settings.json`:
  битый JSON — явная ошибка, перед записью делается бэкап, удаляются только
  хуки с `notify-247.sh`.
- Управление процессом: PID проверяется на принадлежность агенту, EPERM не
  считается «мёртв», ожидание без busy-loop, `start` проверяет `/health`
  перед сообщением об успехе, foreground пробрасывает SIGINT/SIGTERM.
- `247 update` честно сообщает об исходе остановки/перезапуска.
- Профили: имена валидируются (нет path traversal), env-переопределения не
  сохраняются в файл, `--copy-from` создаёт новый machine id, порт — целое
  1–65535. Версия CLI читается из `package.json`.
- e2e-тест CLI ждал строк, которых нет в коде, — исправлен.

  entrypoint создаёт конфиг и сохраняет machine id между деплоями.

## 7. Что осталось и требует твоего решения

1. **Аутентификация агента** — главное. Origin-проверка закрывает атаки из
   браузера, но любой не-браузерный клиент, достучавшийся до порта/туннеля,
   по-прежнему получает shell. Нужен токен: генерация в `247 init`, проверка
   `Authorization: Bearer`/`Sec-WebSocket-Protocol` в агенте, хранение в
   записи подключения на дашборде (миграция Neon) и в хуке. Ломающее
   изменение для существующих подключений.
2. **`@neondatabase/auth` → 0.5.0-beta** (см. §4) — только с тестовым входом.
3. **Сессия дашборда** в браузере сейчас отсутствует (`get-session` → null);
   код авторизации не менялся, скорее всего истекла — нужен повторный вход.
4. `pair 2.ts` — копия старой версии `routes/pair.ts`, в снимке её не было;
   лежит в `scratchpad/removed-files/`. Если это твой файл — скажи.
5. Отладочные роуты веба исполнитель перенёс в `~/.Trash/247-web-debug-routes-*`,
   а не удалил.
6. QR-код пейринга строится внешним `api.qrserver.com` — ссылка с токеном
   уходит третьей стороне.
7. `.claude-plugin/marketplace.json` ссылается на несуществующий
   `packages/plugin-247`; `LICENSE` в репозитории нет (README ссылается).
8. Неблокирующее: 46 lint-предупреждений (`console.log` в релизном скрипте
   и тесте дупликации, non-null assertion в вебе), 19 дубликатов jscpd
   (1,55 % строк), ~15 веб-тестов, которые переписывают логику вместо импорта
   из `src`, `describe.skip` в `apps/agent/tests/e2e/terminal-init.test.ts`,
   ответ `/api/sessions` при недоступном tmux теперь 500 вместо `[]`.
9. Независимое ревью правок не состоялось: оба ревьюера упёрлись в лимит
   сессии. Часть правок веба исполнитель применял скриптом в обход хука
   GateGuard.
